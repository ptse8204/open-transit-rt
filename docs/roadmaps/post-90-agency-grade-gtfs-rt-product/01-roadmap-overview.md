# Roadmap Overview

## Strategy

```text
stabilize Phase 75-90 control plane
→ prove clean checkout repeatability
→ run browser task trials
→ refactor the private Operations Console for maintainability
→ deepen GTFS and GTFS-RT workflows
→ harden connectors, deployment, roles, and adoption
→ cut a local release-candidate source package only when authorized
→ keep evidence tracks separate
```

## Autonomous run

The autonomous kickoff authorizes Phases 91-110 in order. It does not authorize
protected evidence writes, external contact, consumer status movement, real
credentials, publication, tags, GitHub releases, public packages/images, or
stronger claims.
