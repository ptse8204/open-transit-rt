# Open-Source Gap Map For GTFS / GTFS-Realtime Agencies

## Static GTFS lifecycle gap
Need: import, understand changes, validate, fix, publish, rollback.
Phases: 96, 97.

## GTFS-RT usefulness gap
Need: show stale, withheld, suppressed, low-confidence, and missing realtime states.
Phases: 98, 99, 100.

## AVL / GPS integration gap
Need: adapt CSV/API/webhook/device sources without vendor lock-in.
Phases: 101, 102.

## Operations gap
Need: backup, restore drill, upgrade, monitoring, support bundle, maintenance cadence.
Phases: 103, 104.

## Less-technical staff gap
Need: role tours, task scripts, demo datasets, recovery guidance.
Phases: 93, 106.

## Release/adoption gap
Need: clean checkout gates, rc1 package, docs freeze, contributor path.
Phases: 92, 95, 107, 108.

## Evidence/proof gap
Need: safe gates for final-root, consumer, vendor, ETA, compliance proof.
Phase: 109 only, and only as gate prep unless separately authorized.
