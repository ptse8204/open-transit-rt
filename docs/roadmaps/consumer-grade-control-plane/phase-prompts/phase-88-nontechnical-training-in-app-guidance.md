# Phase 88 Prompt — Nontechnical Training And In-App Guidance

## Goal

Help small-agency staff learn and operate the product without a developer sitting beside them.

## Scope

- Role-based onboarding tours: no-developer evaluator, technical helper, operator, integrator.
- First-week checklist.
- Glossary for GTFS, GTFS-RT, telemetry, Trip Updates, Alerts, validators, readiness, evidence.
- Common mistake recovery guidance.
- Printable operator runbook.
- Handoff checklist for internal agency staff.
- In-app contextual examples.

## Do not

- Bury users in phase history.
- Add marketing claims.
- Claim public launch or adoption.
- Write evidence.

## Validation

Baseline validation plus:

```bash
make audit-product-acceptance
make audit-final-claim-review
```
