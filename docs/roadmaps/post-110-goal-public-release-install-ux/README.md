# Open Transit RT — Goal-Based Public Release, Install Confidence, UX, and GTFS-RT Adoption Roadmap

This pack is for Codex. It is designed to prevent the run from stopping after a
single phase or a recommendation. It uses a Codex `/goal` plus an autonomous
kickoff prompt.

## Primary outcomes

1. Publish an actual public `v0.1.0-rc.1` release candidate if release gates pass and authenticated release tooling is available.
2. Establish independent public install confidence from a fresh clone and/or release archive.
3. Validate and improve the Operations Console UX using:

```text
web-design-engineer ~/.agents/skills/web-design-engineer
```

4. Continue improving Open Transit RT beyond UI polish: GTFS-RT usefulness,
   interoperability, fixtures, connector starter kits, realtime QA, alerts,
   safe operator commands, small-host deployability, and contributor adoption.
