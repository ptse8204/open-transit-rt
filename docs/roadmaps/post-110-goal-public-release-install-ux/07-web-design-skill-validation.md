# Web Design Skill UX Validation Policy

For UX phases, Codex must use:

```text
web-design-engineer ~/.agents/skills/web-design-engineer
```

## Required phases

- Phase 114
- Phase 118
- Optional: Phase 119 and Phase 126

## Review dimensions

- information hierarchy;
- page density;
- visual grouping;
- typography;
- spacing;
- primary action clarity;
- form design;
- table scanning;
- mobile/responsive behavior;
- keyboard and focus behavior;
- accessible status indicators;
- empty states;
- help text;
- first-run task flow;
- nontechnical operator comprehension.

## Required artifacts

```text
docs/ux/web-design-skill-review-phase-114.md
docs/ux/web-design-skill-review-phase-118.md
```

If the skill is unavailable, record the exact attempted access path or command
and complete a fallback UX review. Do not pretend the skill was used.
