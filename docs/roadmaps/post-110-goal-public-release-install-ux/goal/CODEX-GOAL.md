
## Why this Goal is shaped this way

OpenAI's Codex Goals guidance says a strong Goal should define outcome,
verification surface, constraints, boundaries, iteration policy, and blocked
stop condition. This Goal does that for the Open Transit RT roadmap.

## Completion evidence

The Goal is complete only when the repo contains:

- `docs/handoffs/phase-132.md`;
- a final release status artifact;
- committed handoffs for Phases 111-132;
- independent install confidence results;
- Web Design Skill UX review artifacts;
- final protected-path and prepared-only consumer tracker checks;
- final claim-boundary review.

If the public release cannot be published because credentials/tooling are
unavailable, the Goal is not allowed to fake publication. It must record the
exact blocker, continue safe phases, and close with a truthful release status.
