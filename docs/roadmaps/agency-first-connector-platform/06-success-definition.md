# Success Definition

The Phase 61+ roadmap is successful when Open Transit RT is usable as an agency-facing product, not just as a backend repo.

## Product Success

A small agency operator can:

1. open the private Operations Console;
2. understand what to do first;
3. set up agency/feed metadata;
4. import or prepare static GTFS;
5. see all five public feed outputs;
6. connect or test telemetry;
7. understand connector/plugin options;
8. review validator/readiness state;
9. run or understand support diagnostics;
10. avoid unsupported public claims.

## Developer Success

A developer integrator can:

1. find Connector Hub docs;
2. understand plugin means sidecar/manifest/command adapter, not dynamic backend code loading;
3. use telemetry connector examples;
4. use prediction sidecar examples;
5. run conformance checks;
6. avoid committing real credentials or vendor payloads.

## Roadmap Completion

The roadmap is complete when:

- Phase 61 through Phase 67 close and pass audits;
- protected evidence/consumer paths remain unchanged unless explicitly authorized;
- no unsupported claims are introduced;
- agency UI is usable without reading phase history;
- connector/plugin model is visible and safe;
- release-candidate/installability path is clear;
- accessibility and in-app help are present.

## Optional Evidence

Phase 68+ evidence tracks are optional. The product can be successful before agency adoption, final-root proof, consumer acceptance, or real vendor integration evidence exists.
