Quickstart

Start with the local evaluator when you want to see the product shape without publishing anything or contacting external systems.

Run Locally

make check
make agency-app-up

Open http://localhost:8080/admin/operations and use Start Here in the private Operations Console.

Stop the app with:

make agency-app-down
