The Local Flow

  1. Start the appA technical helper runs the local startup flow from the release or repository.
  2. Open local sign-inStaff open /admin/local-login on the local machine and choose Start setup.
  3. Follow the workflowUse Start setup, Import GTFS, Check feeds, Connect vehicles, Review realtime, Fix issues, Share public URLs, and Maintain system.
  4. Escalate only when neededAsk for technical help for hosting, validators, secrets, real connector endpoints, or production network controls.
