Connector support

Know what works today.

Open Transit RT separates local-supported connector paths from roadmap candidates so agencies and integrators can choose a safe starting point.

Plain rule

Supported today means implemented for local/self-hosted evaluation. Planned means useful direction, not compatibility.

Works Today / Local-Supported

Telemetry adapters

CSV replay, HTTP polling, webhook sidecar, generic JSON transform, and authenticated POST /v1/telemetry.

Prediction

Deterministic built-in predictor and external HTTP predictor adapter / shadow mode where configured.

Validation

MobilityData static GTFS and GTFS Realtime validator wrappers when tooling is installed.

Feeds and monitoring

Monitoring/export helper, /public/feeds.json, static GTFS, Vehicle Positions, Trip Updates, and Alerts URLs.

Planned / Candidate

  • TheTransitClock behind the prediction adapter.
  • Real vendor AVL payload adapters.
  • SIRI to GTFS-RT bridge.
  • GTFS-Flex, GTFS-ride, GTFS-Pathways, and GTFS-Fares v2 QA.
  • OpenTripPlanner and OneBusAway compatibility checks.
  • Transitland / Mobility Database discovery-readiness workflows.
