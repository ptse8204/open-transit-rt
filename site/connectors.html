Connector support

Connect vehicle data through clear, tested paths.

Open Transit RT keeps external systems outside the core backend. Start with a local-supported connector shape, then let the deployment owner add real endpoints, credentials, and retention rules.

Plain rule

Supported means implemented for local/self-hosted evaluation. Candidate means useful direction, not compatibility.

Works Today / Local-Supported

Vehicle data

CSV replay, HTTP polling, webhook sidecar, generic JSON transform, and authenticated POST /v1/telemetry.

Prediction

Deterministic built-in predictor plus external HTTP predictor adapter and shadow mode.

Validation

MobilityData static GTFS and GTFS Realtime validator wrappers when tooling is installed.

Monitoring

Monitoring/export helper and local health summaries.

Discovery

/public/feeds.json, static GTFS, Vehicle Positions, Trip Updates, and Alerts URLs.

Conformance

Local synthetic fixtures and adapter checks for telemetry, prediction, validators, monitoring, and discovery.
