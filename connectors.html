Connector catalog

Choose the safest path for vehicle data.

Start with the connector shape that matches your data source: file replay, polling, webhook sidecar, JSON transform, authenticated telemetry POST, prediction, validation, monitoring, or discovery metadata.

These paths do not prove compliance, production readiness, consumer acceptance, vendor compatibility, hardware certification, hosted service availability, SLA coverage, production AVL reliability, production-grade ETA quality, or real-world ETA accuracy.

Vehicle / GPS / AVL

Send observations

Use CSV replay, HTTP polling, webhook sidecar, JSON transform, synthetic examples, or authenticated POST /v1/telemetry.

Prediction

Keep ETA work replaceable

Use the deterministic predictor, external HTTP adapter, shadow mode, and fail-closed behavior. TheTransitClock remains a candidate only.

Validator

Check feeds

Run allowlisted MobilityData static GTFS and GTFS Realtime validator wrappers, then review private validation health.

Monitoring / Export

Export health safely

Use local summaries, notify drafts, and deployment-owned monitoring boundaries.

Consumer / Discovery

Review public metadata

Check /public/feeds.json and the four feed URLs without claiming submission or acceptance.

Extension Model

Use sidecars

Prefer manifests and sidecars. Do not load arbitrary backend code. Keep conformance tests required.
