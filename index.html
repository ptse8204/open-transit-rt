First Browser Path

Use the same order in the public docs and the private UI. Shell commands are technical-helper startup, not the first step for a no-developer review.

Start in the browser

Use the local URL from a technical helper, normally http://localhost:8080/admin/operations.

Open Agency Operations Cockpit / Start Here

Review no-developer and technical-helper paths, first-run tasks, and boundaries.

Review setup

Use setup wizard and publication metadata pages to see what is configured or missing.

Import or review GTFS

Use Browser GTFS Import for ZIP upload or safe URL import, or inspect the active published schedule.

Check five feed URLs

Review discovery metadata, schedule, Vehicle Positions, Trip Updates, and Alerts in Feed Health.

Review operations surfaces

Open feed health, readiness, validation, telemetry, connectors, and maintenance.

Understand what remains

Use Help and readiness boundaries before making deployment or stronger public claims.

Two Startup Roles

A browser reviewer and a technical helper do different work. Keep those paths separate so local commands do not become a barrier to product review.

No-developer review

Start with the browser URL

Open the private Operations Console URL provided by a technical helper. Click Agency Operations Cockpit / Start Here, then follow setup, GTFS, feed health, readiness, validation, telemetry, connectors, maintenance, and help.
