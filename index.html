Self-hosted GTFS and GTFS Realtime

Run your transit feed from a browser.

Open Transit RT helps small agencies and civic technologists import GTFS, check public feed URLs, connect vehicle data, and see what needs attention without turning every task into command-line work.

Start locally Tour the browser UI Watch the walkthrough

Built for local and self-hosted evaluation. It does not prove compliance, production readiness, consumer acceptance, vendor compatibility, SLA, AVL reliability, or ETA quality.

Work in order

  1. Start setupOpen the local sign-in page after a helper starts the app.
  2. Import GTFSUpload or review a schedule and see validation guidance.
  3. Check feedsReview feeds.json, static GTFS, Vehicle Positions, Trip Updates, and Alerts.
  4. Connect vehiclesChoose a local connector shape before using real device data.
  5. Fix issuesSee the next action and when technical help is needed.

Agency staff

Use the browser after startup

Open the local sign-in page, choose Start setup, then follow the Operations Console workflow. Normal review does not require curl, DevTools, header extensions, JWTs, or manually pasted cookies.

Technical helper

Start the local app once

Use the release or repository startup flow, then hand the local browser URL to staff. Keep deeper deployment, validator, connector, and secret work outside the normal user path.

What You Can Connect

Supported today

Local connector examples, authenticated telemetry ingest, deterministic prediction, validator wrappers, monitoring/export helpers, and public feed URLs.

See connector support

Deployment-owned setup

Real endpoints, credentials, device tokens, retention, monitoring destinations, and vendor payload mappings stay under the deployment owner.

Planned candidates

TheTransitClock, vendor AVL adapters, SIRI bridging, OTP/OBA checks, and discovery-readiness workflows remain roadmap items until implemented and tested.

Know What Is Not Proven

Open Transit RT can help you evaluate and prepare GTFS / GTFS-Realtime workflows. Outside claims still require deployment-specific review, external evidence, and agency-owned decisions.
