Browser tour

Follow the same path staff use in the console.

The Operations Console is organized around a simple sequence: start setup, import GTFS, check feeds, connect vehicles, review realtime, fix issues, share URLs, and maintain the system.

What stays technical?

Startup, production hosting, validator tooling, device secrets, real connector endpoints, and deployment monitoring still need a technical helper.

Console Workflow

1

Start setup

Confirm agency metadata, local session state, and the next browser action.

2

Import GTFS

Upload or review a schedule, then open the GTFS Workbench for required files and validation feedback.

3

Check feeds

Review the five expected feed URLs and see which ones are present, stale, missing, or blocked.

4

Connect vehicle data

Choose the safest telemetry connector shape before any deployment-owned source is enabled.

5

Review realtime

Check fresh vehicles, stale rows, withheld Trip Updates, Vehicle Positions, and Alerts.

6

Fix issues

Use GTFS quality, validation health, readiness, and help pages to find the next owner and action.

7

Share public URLs

Copy discovery and feed URLs only after the deployment owner confirms the public base URL.

8

Maintain system

Review routine checks, backup/restore guidance, support summary notes, and helper needs.

Use The Tour For Evaluation

The UI helps local and self-hosted evaluation. It does not create evidence, contact consumers or vendors, prove public launch, or replace deployment-owned review.
