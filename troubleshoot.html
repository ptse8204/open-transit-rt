Troubleshooting

Fix the next issue.

Start from the browser status, open the linked page, and ask for technical help only when the next action depends on setup, tooling, secrets, or hosting.

First stop

Use the Start page workflow. It is designed to show the first missing, blocked, or needs-review step.

Common Issues

Sign-in

Local login missing

Confirm the local app is running and local/demo sign-in is enabled. Production deployments use deployment-owned access.

GTFS

No active schedule

Open Import GTFS, then GTFS Workbench. Ask for help if the ZIP is missing or import fails.

Feeds

URL missing or blocked

Open Feed Health and follow the linked next action for that row.

Vehicles

Stale telemetry

Open Devices and Telemetry Freshness. Check connector setup and stale thresholds.

Validators

Tooling unavailable

Ask a helper to install or configure allowlisted validator tooling.

Sharing

Not ready to publish

Confirm public hosting, license, contact metadata, and deployment ownership before sharing URLs.
