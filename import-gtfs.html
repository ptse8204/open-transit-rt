GTFS

Import GTFS.

Use the browser to load or review a schedule, confirm the active feed version, and see what needs attention before checking public feed URLs.

Start in the console

Open Import GTFS from the Start page. Use GTFS Workbench when you need to review files, import history, or validation guidance.

What To Do

  1. Choose the schedule ZIPUse public-safe or synthetic data for evaluation. Do not use private agency data in public demos.
  2. Import or reviewConfirm that a feed version is active and required GTFS files are present.
  3. Review validationIf validator tooling is installed, review the latest static GTFS result and warnings.
  4. Check feedsAfter GTFS is active, open Feed Health and confirm the schedule URL is present.

When To Get Technical Help

No schedule ZIP

Ask for the current public-safe GTFS ZIP or a synthetic evaluation feed.

Import fails

Ask for the import log, file validation, and database migration state.

Validators missing

Ask a helper to install or configure the allowlisted validator tooling.
